## Подтвержденные общие условия

- Офлайн-этап: 23 сентября 2026 года, МВЦ EXPO, проспект Мәңгілік Ел, 53/1, Астана.
- Личное присутствие каждого участника обязательно.
- Команда состоит из 1–3 участников; один человек — только в одной команде и с одним проектом.
- Основная разработка идет только в репозитории, выданном платформой.
- За каждый отчетный час необходим подтвержденный промежуточный результат.
- Организаторы могут проверять историю Git, метаданные, работоспособность и вклад каждого участника.
- Проект должен быть развертываемым и проверяемым экспертами из конкурсного репозитория.
- README должен содержать установку, настройку, запуск, проверку, зависимости, переменные окружения и ограничения.
- Разрешены AI-инструменты и агенты. Для снятия противоречия между источниками команда применяет Codex и AI-агента обязательно.
- Соревновательная часть официально идет 23 сентября с 13:00 до 18:00; check-in — 09:00–12:00.
- Технические требования и баллы теперь устанавливаются отдельным ТЗ каждой Задачи; прежняя единая таблица удалена.
- Невозможность запуска строго по README означает недопуск без дополнительных пояснений и исправлений.

## Расхождения и консервативные решения

1. Лендинг говорит, что команда должна использовать Codex. Положение 5.4.12 разрешает любые AI-инструменты и говорит, что Codex не обязателен, если кейс не требует иного. Инструкция участника требует использовать AI-агента. Решение команды: использовать Codex/AI-агента и сохранять историю работы.
2. Положение требует промежуточный результат команды каждый час, а не буквально коммит каждого участника. Бриф Андрея устанавливает более строгое внутреннее правило: содержательный коммит Андрея и Михаила каждый час.
3. Новая редакция прямо разрешает заранее подготовленные технические компоненты, собственные библиотеки, шаблоны и инфраструктуру, если это не готовый продукт и не основная функциональность. Пользовательский бриф содержал более строгий запрет заранее написанного кода; его можно сохранить как внутреннюю меру снижения риска, но это уже не буквальное требование положения.
