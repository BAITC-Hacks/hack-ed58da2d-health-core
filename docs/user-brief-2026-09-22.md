# Исходный бриф от команды

Дата сохранения: 22 сентября 2026 года.

## Команда

- Андрей: backend, база данных, deploy на удаленный сервер, составление и проверка воспроизводимости `README.md`.
- Михаил: frontend и product management.
- Оба участника должны делать не менее одного содержательного коммита в час, чтобы был виден личный вклад каждого.

## Задача

За 5 часов офлайн на мероприятии разработать работающий продукт, решающий выбранный кейс. Кейс станет известен в день мероприятия. Предварительно рассматривается трек «Инновации», но команда может выбрать другой трек.

Код заранее писать нельзя, ранее написанный код использовать нельзя. Разработка выполняется самостоятельно и с помощью AI/агентов только во время выделенной соревновательной части. Встраивание AI в продукт не обязательно, если это не требуется кейсом или не улучшает решение.

Проект должен быть рабочим и полностью воспроизводимым по инструкции. `README.md` должен описывать deploy от начала до конца.

## Предпочтительный стек

- Python 3 и FastAPI для backend.
- PostgreSQL 17 для базы данных.
- Доступные расширения PostgreSQL: `vector`, `http`, `pgcrypto`, `unaccent`, `pg_stat_statements`; разрешено добавлять необходимые расширения.
- Vue 3 для frontend.
- При необходимости: плагины мультиязычности, диаграммы, Bootstrap и другие стандартные UI-компоненты.
