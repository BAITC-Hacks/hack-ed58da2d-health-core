- Место: МВЦ EXPO, проспект Мәңгілік Ел, 53/1, Астана.
- Офлайн-присутствие каждого участника обязательно.

## Регистрация, команда и check-in

- Регистрация завершилась 19 сентября в 23:59.
- Формирование и изменение команды было доступно до 20 сентября в 23:59; позже — только с предварительного согласия Организатора.

## Присутствие

- С check-in до официального окончания участник лично находится на площадке.
- После начала соревновательной части разработка выполняется исключительно на площадке.
- Временный выход допускается только с предварительного разрешения; общее отсутствие — не более 60 минут.
- Экстренные медицинские, семейные и связанные с безопасностью обстоятельства допускаются с уведомлением при первой возможности.
- Дополнительная инструкция требует находиться в зоне весь последний час и фиксировать каждый вход/выход.

## Что разрешено готовить заранее

- Запрещено представлять ранее созданный готовый продукт, уже обладавший основной конкурсной функциональностью.
- Основная функциональность выбранной Задачи должна быть разработана во время соревновательной части.
- Теперь прямо разрешены заранее подготовленные технические компоненты, собственные библиотеки, шаблоны, инструменты и инфраструктурные решения, если они не являются готовым продуктом или основной частью решения.
- Open-source код, библиотеки, модели, датасеты, шаблоны и другие внешние компоненты разрешены при соблюдении лицензий и обязательном раскрытии.
- Существенные части чужого решения нельзя скрывать или представлять как собственную разработку.

## Репозиторий и часовые результаты

- Один Проект подается только по одной Задаче.
- Основная разработка идет исключительно в Репозитории, автоматически созданном Организатором.
- Сторонние закрытые репозитории нельзя использовать для основной разработки, хранения кода или передачи финальной версии.
- Каждый отчетный час должен завершаться подтвержденным результатом: кодом, функцией, дизайном, архитектурой, моделью, тестом, данными или другим реальным прогрессом.
- Организатор может проверять Git-историю, метаданные, работоспособность и вклад каждого участника.
- Облачные сервисы, внешние API, онлайн-разработка и удаленные инструменты разрешены при личном присутствии и сохранении основной истории в выданном Репозитории.

## AI-инструменты

- Разрешены любые AI-инструменты и AI-агенты для кода, UI, данных, тестирования, архитектуры и документации.
- Codex не является обязательным по этому положению, если конкретная Задача не требует иного.
- Лендинг и отдельная инструкция содержат более строгие формулировки об AI-агенте/Codex; безопасная практика команды — использовать Codex и сохранять подтверждаемую историю.

## README и безусловная воспроизводимость

README обязан содержать:

- назначение решения;
- архитектуру;
- технологии;
- установку и запуск;
- зависимости;
- параметры окружения;
- порядок проверки основного сценария;
- системные требования и прочие необходимые настройки.

Если итоговую версию невозможно запустить по инструкциям из Репозитория, команда не допускается к дальнейшему отбору. Дополнительные пояснения и исправления не принимаются.

Ключевая функциональность должна проверяться без личных аккаунтов участников, персональных подписок и закрытых учетных записей. Для внешних сервисов и API команда предоставляет тестовые доступы, демонстрационные аккаунты либо другой самостоятельный способ проверки.

## Дисквалификация

К прежним основаниям добавлена широкая формулировка об иных действиях или бездействии, нарушающих справедливость, добросовестность, разумность, состязательность, равенство условий или достоверность результатов.

Основные риски:

- отсутствует подтвержденный результат за любой час;
- участник отсутствует без разрешения;
- не пройден check-in;
- основная разработка идет вне выданного Репозитория;
- история разработки не подтверждается;
- использовано преимущественно чужое решение без раскрытия;
- атаки, вредоносный код, вмешательство в системы или проекты других команд;
- давление на экспертов, неэтичное поведение или нарушение правил площадки.
